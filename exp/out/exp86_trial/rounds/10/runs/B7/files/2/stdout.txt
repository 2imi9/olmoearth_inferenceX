**Which is right? Neither can be picked.** The maps describe different times, so where they differ, either the ground changed between Sep 2017 and Apr 2018 (seasonal cycles included) or one map is wrong - the decisions alone cannot separate those. Labels for only one date would grade only that date's map. To settle it, each map needs a reference of its own date: a tool can plan the windows to label per date with `olmoearth_plan_label_sample` (needs a budget), and once a reviewer has supplied 0/1 labels for the planned windows, `olmoearth_estimate_map_error` gives each map's error rate - no tool of this agent fetches ground-truth labels itself.

All 1,570 differing windows (class + both margins, window order) are in `compare_differing_eec2555155.json`.
