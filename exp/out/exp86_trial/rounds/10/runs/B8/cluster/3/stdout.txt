Two caveats worth stating:
- This ranking uses the logit margin; on Ai2's suite, one-minus-top-probability ranked errors better on 14 of 16 multi-class tasks (exp76), so the evidence for this particular signal form only partly covers this case.
- A low margin means "least decided," not "probably wrong": the margin is not an error probability, and the review set is targeted, not a random sample — don't divide its errors by 819 to get an error rate. If you want an honest error estimate later, use `olmoearth_plan_label_sample` on the same scores file.
