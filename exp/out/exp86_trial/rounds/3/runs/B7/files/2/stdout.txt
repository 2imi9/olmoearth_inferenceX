(50 of 1,570 listed; I can list more or save a full window index if useful.)

**Which one is right: I can't grade it, and that's the correct answer.** The maps are 216 days apart, so any differing window either changed on the ground (seasonality included) or is wrong in one map — the scores alone cannot separate those. Two concrete points from the run:

- No reference labels were supplied for either date, so grading isn't even possible here.
- Even with labels: published measurements show the more confident side is right on only ~51–70% of differing windows, so picking "the side with the bigger margin" (map A here) would not identify a winner.

To resolve it you'd need a dated reference per period (e.g. photo-interpreted or expert-labeled windows for Sep 2017 **and** Apr 2018); then `olmoearth_classification_metrics` against each map separately tells you where each failed. Want me to plan such a label set?
