## Which windows, and why

The tool ranked all **72 valid windows** (100 sampled on a 10x10 grid; 28 dropped as no-data) by **margin = distance from the decision value 0.5**. Windows nearest 0.5 are the ones the model is least decided on, so errors concentrate there first; windows with scores near 0 or 1 are the most confident and come last. ## Caveats you should know

- **Assumption:** the score is treated as P(positive) *for ranking only* — the margin orders suspicion, it is **not a probability of error**, and no recorded experiment grades a regression score read as a probability.
- This review set is chosen to hold errors, so it is **not a sample**: don't divide its mistakes by its size. To estimate how wrong the map really is, run `olmoearth_plan_label_sample` with the saved scores file.
