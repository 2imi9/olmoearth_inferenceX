# OlmoEarth inferenceX overview
`inferencex_overview.tex` is the standalone TikZ source; `inferencex_overview.pdf` is the compiled figure.
From `docs/figures/tikz/`, compile with `pdflatex -interaction=nonstopmode inferencex_overview.tex`.
The figure content is generated from `../inferencex_overview.py`.
Change content in `inferencex_overview.py` first, then update the TikZ source and recompile.
